Reduce complexity so users can understand and act faster.

## Focus Areas

- Too many choices at once
- Repetitive copy
- Multi-step flows with unnecessary friction
- Dense layouts hiding the primary action

## Method

1. Define the single primary user goal.
2. Remove, defer, or collapse secondary information.
3. Group related elements and sequence them logically.
4. Rewrite labels and controls so intent is obvious.

## Preferred Techniques

- Progressive disclosure
- Better defaults
- Fewer visible options per step
- Shorter copy with clearer verbs
- Clear empty, loading, and success states

## Success Check

- A first-time user can tell what to do in seconds.
- The interface asks for less attention and memory.
- The primary task takes fewer steps or decisions.

# Spatial Design Reference

## Goals

- Create rhythm through varied spacing.
- Use grouping and separation to communicate structure.
- Choose simple layout tools before complex ones.

## Spacing Rhythm

- Tight: 8-12px for closely related items
- Standard: 16-24px for component internals
- Section: 32-64px between major groups
- Hero / page transitions: 72px+

## Layout Guidance

- Use Flexbox for one-dimensional alignment.
- Use Grid for coordinated rows and columns.
- Prefer `gap` over ad hoc margins for sibling spacing.
- Use asymmetry intentionally when it strengthens focus.

## Container Thinking

- Not everything needs a card.
- Avoid card-inside-card nesting.
- Use whitespace and dividers before adding containers.

## Common Mistakes

- Same padding everywhere
- Over-centered layouts
- Repetitive identical card grids
- Arbitrary z-index and spacing values

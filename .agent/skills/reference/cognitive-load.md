# Cognitive Load Reference

## Working Memory Rule

Assume users can comfortably process only a small number of choices or concepts at once. If a screen asks them to compare, remember, and choose too much simultaneously, simplify it.

## 8-Item Checklist

1. More than 4 meaningful choices visible at once
2. Repeated information competing for attention
3. Important actions buried among low-priority actions
4. Users must remember information from a previous step
5. Dense copy with no grouping or scanning structure
6. Too many visual treatments competing at once
7. Advanced options shown before basic decisions are made
8. Unclear next step after completion or failure

## Rating

- 0-1 failures: low load
- 2-3 failures: moderate load
- 4+ failures: critical load

# Typography Reference

## Goals

- Make reading order obvious.
- Improve scanability before adding decoration.
- Use fewer type roles, but make them more distinct.

## Practical Scale

- Display: 40-72px
- H1: 32-48px
- H2: 24-32px
- H3: 18-24px
- Body: 16-18px
- Meta / labels: 12-14px

Use `clamp()` for fluid type when possible.

## Pairing Guidance

- One expressive display face + one readable body face is enough.
- If you use one family only, create hierarchy through size, weight, width, and spacing.
- Avoid too many fonts in one interface.

## Readability

- Comfortable paragraph measure: 45-75 characters
- Typical body line-height: 1.45-1.7
- Tighten headings slightly, loosen dense body copy slightly

## Hierarchy Rules

- Increase contrast between levels; do not rely on tiny size changes.
- Supporting text should feel quieter than primary text.
- Headings need space above them to feel important.

## Common Mistakes

- Too many similar heading sizes
- Body text below 16px on mobile
- Meta text with the same color and weight as body text
- Centering long-form text without a strong reason

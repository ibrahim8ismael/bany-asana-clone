# Color And Contrast Reference

## Goals

- Use color to communicate hierarchy and meaning.
- Keep contrast accessible.
- Prefer cohesive palettes over random accents.

## Palette Structure

- Dominant brand color
- 1-2 supporting accents
- Tinted neutrals
- Semantic colors for success, warning, error, info

## Contrast Targets

- Body text: 4.5:1 minimum
- Large text: 3:1 minimum
- UI controls and focus indicators: 3:1 minimum

## Preferred Practices

- Tint neutrals toward the brand hue.
- Use OKLCH where supported for more consistent scales.
- Keep semantic color meaning stable across the product.

## Avoid

- Gray text on saturated surfaces
- Pure black or pure white for large surfaces
- Relying on color alone to communicate state
- Random gradients with no semantic purpose

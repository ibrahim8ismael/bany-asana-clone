Design onboarding that gets users to value quickly.

## Preparation

Read `/frontend-design` first and use existing design context if available. If not, run `/teach-impeccable`.

## Focus Areas

- Empty states that explain what to do next
- Setup flows that ask only for what is needed now
- Sample data, templates, or walkthroughs that reduce blank-screen anxiety
- Clear success moments after first completion

## Method

1. Identify the activation event.
2. Remove friction before that event.
3. Guide users with checklists, defaults, examples, or seeded content.
4. Confirm progress and show the next best action.

## Never

- Force long tours before users can act.
- Hide the first meaningful action behind multiple dead ends.
- Over-explain when an example would teach faster.

## Success Check

- First-time users can complete the core action quickly.
- Empty states feel useful, not dead.
- The product feels teachable from inside the interface.

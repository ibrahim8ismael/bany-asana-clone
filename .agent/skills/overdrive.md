Take the strongest design direction and push it further with confidence.

## Preparation

Read `/frontend-design` first. If context is missing, run `/teach-impeccable`.

## Method

1. Identify the current strongest visual idea.
2. Increase contrast, hierarchy, and memorability around that idea.
3. Remove timid compromises that dilute the concept.
4. Re-check usability, accessibility, and performance.

## Good Uses

- Hero moments that need more impact
- Differentiation from generic competitors
- Product launches, marketing pages, flagship flows

## Never

- Add random intensity without a concept.
- Break comprehension in the name of style.
- Turn every screen into the hero moment.

## Success Check

- The result feels more distinctive and memorable.
- The main idea is clearer, not noisier.

# Personas Reference

## Suggested Default Personas

### Alex - Power User
- Cares about speed, efficiency, shortcuts, and information density
- Friction signals: too many clicks, weak bulk actions, poor keyboard flow

### Jordan - First-Timer
- Cares about clarity, guidance, confidence, and obvious next steps
- Friction signals: jargon, dead ends, unclear labels, missing empty states

### Sam - Mobile Multitasker
- Cares about thumb reach, quick scanning, and reliable touch behavior
- Friction signals: tiny targets, overflow, hover-only actions, dense forms

## Selection Guide

- Productivity / dashboards: Alex + Jordan
- Consumer tools / onboarding: Jordan + Sam
- Mobile-first experiences: Sam + Jordan
- Expert workflows: Alex + one project-specific persona

## Red Flag Format

For each persona, describe:

- primary goal
- exact element or interaction that fails
- likely consequence

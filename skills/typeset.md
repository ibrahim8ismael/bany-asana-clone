Use typography as a layout and communication tool, not just styling.

## Focus Areas

- Weak heading hierarchy
- Inconsistent sizes or weights
- Uncomfortable line length or line height
- Dense text blocks with poor scanning
- Labels, body copy, and metadata that blur together

## Method

1. Define reading order.
2. Increase contrast between levels.
3. Improve rhythm with spacing, line height, and measure.
4. Make supporting text quieter than primary text.

## Preferred Techniques

- Fluid type with `clamp()`
- Distinct display and body roles
- Stronger spacing around headings
- Better line length for paragraphs

## Success Check

- Users can tell what to read first, second, and third.
- Long-form copy feels easier to scan.
- Metadata supports instead of competing.
